1. Вероятностные нейронные сети (PNN): архитектура, назначение слоев и принцип оценки плотности вероятности
Вероятностная нейронная сеть (PNN, Probabilistic Neural Network) - это тип нейронной сети, который используется для решения задач классификации на основе теории вероятностей. Сеть оценивает, насколько входной объект похож на примеры каждого класса, и на основании полученных оценок выбирает наиболее подходящий класс.
Главное преимущество PNN заключается в быстром обучении. В отличие от классических многослойных нейронных сетей, ей не требуется длительная настройка весов с помощью обратного распространения ошибки. Обучение в основном сводится к сохранению обучающих примеров и настройке параметра сглаживания.
Архитектура PNN включает четыре основных слоя.
Входной слой принимает входные данные и передает их следующему слою.
Слой образцов (Pattern Layer) содержит нейроны, соответствующие обучающим примерам. Сеть сравнивает входной объект с сохраненными примерами, обычно используя расстояние между ними. Чем ближе объекты друг к другу, тем выше значение их сходства.
Слой суммирования (Summation Layer) объединяет результаты нейронов предыдущего слоя отдельно для каждого класса. На этом этапе оценивается плотность вероятности принадлежности объекта к определенному классу.
Выходной слой (Output Layer) сравнивает полученные оценки и выбирает класс с наибольшим значением. Например, при классификации писем сеть определяет, относится письмо к спаму или к обычным сообщениям.
Основой работы PNN является оценка плотности вероятности. Она позволяет определить, насколько характерны признаки входного объекта для каждого класса. Для этого сеть использует обучающие примеры и функцию ядра, которая оценивает сходство входного объекта с каждым примером.
Общий вид оценки плотности вероятности:
f(x) = (1 / (n * (2 * pi)^(d/2) * sigma^d)) * SUM(exp(-||x - x_i||^2 / (2 * sigma^2)))
Суммирование выполняется по обучающим примерам соответствующего класса. Параметр sigma определяет степень сглаживания оценки: при небольшом значении сеть сильнее реагирует на близкие примеры, а при большом формирует более сглаженную оценку.
Таким образом, PNN классифицирует объекты путем оценки вероятностных распределений классов, а не за счет длительного обучения весов. Такие сети применяются для распознавания образов, диагностики и классификации сигналов.
2. Компоненты временного ряда в аддитивной модели Meta Prophet. Суть генерального уравнения декомпозиции (разложения ряда)
Meta Prophet - это библиотека для прогнозирования временных рядов, разработанная компанией Meta. Она позволяет строить прогнозы на основе исторических данных, учитывая тенденции, сезонные колебания и влияние отдельных событий, например праздников.
Временной ряд представляет собой последовательность значений, упорядоченных по времени. Примерами могут быть ежедневные продажи магазина, количество посетителей сайта или ежемесячная выручка компании.
В аддитивной модели Prophet временной ряд представляется как сумма нескольких компонентов. Такой подход называется декомпозицией, поскольку исходные данные раскладываются на составляющие, каждая из которых описывает определенную закономерность.
Генеральное уравнение модели:
y(t) = g(t) + s(t) + h(t) + e(t)
Основные компоненты модели:
Тренд (g(t)) отражает общее направление изменения данных во времени. Например, постепенный рост количества пользователей сайта. Prophet может моделировать линейный тренд или рост с ограничением.
Сезонность (s(t)) описывает закономерности, которые повторяются через определенные промежутки времени. Например, изменение продаж в зависимости от дня недели или времени года. Prophet позволяет учитывать недельную, годовую и другие виды сезонности.
Праздники и специальные события (h(t)) учитывают влияние конкретных дат на прогнозируемые значения. Например, в праздничные дни спрос на некоторые товары может возрастать. Для этого в модель передают информацию о соответствующих событиях.
Ошибка (e(t)) отражает случайные колебания и факторы, которые модель не смогла объяснить с помощью остальных компонентов.
Аддитивная модель предполагает, что влияние компонентов складывается. Например, если базовый уровень продаж составляет 100 единиц, тренд добавляет 20, сезонность - 15, а праздник - 10, то прогноз составит 145 единиц без учета ошибки.
В Prophet также существует мультипликативный подход, при котором сезонные эффекты зависят от уровня тренда. Он подходит для ситуаций, когда амплитуда колебаний увеличивается вместе с ростом показателя.
Таким образом, декомпозиция позволяет не только получить прогноз, но и понять, за счет каких факторов изменяется временной ряд. Это делает модель удобной для анализа продаж, спроса, посещаемости и других показателей, зависящих от времени.
3. Подходы к приведению слов к базовой форме: сравнительный анализ стемминга (Stemming) и лемматизации (Lemmatization) в NLTK
При обработке естественного языка одно и то же слово может встречаться в разных формах. Например, слова «работать», «работает» и «работал» имеют близкое значение, но отличаются написанием. Чтобы алгоритм мог эффективнее анализировать текст, такие формы часто приводят к единому представлению.
В библиотеке NLTK для этого используются два основных подхода: стемминг и лемматизация.
Стемминг (Stemming) - это процесс удаления окончаний и других частей слова по определенным правилам. В результате получается основа, которая не обязательно является самостоятельным словом или соответствует его словарной форме. Преимущество стемминга заключается в простоте и высокой скорости работы.
Лемматизация (Lemmatization) - это приведение слова к его нормальной словарной форме, которая называется леммой. В отличие от стемминга, лемматизация учитывает языковые особенности и может использовать словари и грамматическую информацию. Поэтому результат обычно представляет собой полноценное слово.
Например, английские слова cars и car могут быть приведены к car, а формы глагола running и ran при правильном определении части речи - к run.
В NLTK стемминг можно выполнять с помощью PorterStemmer, а лемматизацию - с помощью WordNetLemmatizer.
Пример стемминга:
from nltk.stem import PorterStemmer
stemmer = PorterStemmer()
words = ["playing", "played", "plays"]
for word in words:
    print(stemmer.stem(word))
Пример лемматизации:
from nltk.stem import WordNetLemmatizer
lemmatizer = WordNetLemmatizer()
words = ["cars", "running", "played"]
for word in words:
    print(lemmatizer.lemmatize(word))
При использовании WordNetLemmatizer важно учитывать, что по умолчанию слово рассматривается как существительное. Для правильной обработки глаголов необходимо передать соответствующую часть речи. Кроме того, для работы лемматизатора нужно загрузить данные WordNet из NLTK.
Основные различия между подходами:
Стемминг удаляет части слова по правилам и обычно работает быстрее.
Лемматизация использует лингвистическую информацию и чаще возвращает корректную словарную форму.
Результат стемминга может не быть полноценным словом.
Лемматизация обычно точнее, но может требовать больше ресурсов.
Стемминг подходит для задач, в которых важна скорость обработки большого объема текста, например для поиска и индексирования документов. Лемматизация предпочтительнее, когда важно сохранить смысл слов и корректно обрабатывать их грамматические формы.
Таким образом, оба метода уменьшают количество различных словоформ, которые приходится обрабатывать алгоритму. Выбор зависит от задачи: стемминг проще и быстрее, а лемматизация обеспечивает более лингвистически корректный результат.
