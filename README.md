1. Что такое SHAP и как он объясняет предсказания модели
SHAP - метод интерпретации моделей машинного обучения, который позволяет понять, как отдельные признаки влияют на результат предсказания. Он показывает вклад каждого признака относительно базового значения, то есть среднего или ожидаемого результата модели.
Например, при прогнозировании стоимости квартиры площадь может повышать предсказанную цену, а большая удалённость от метро - снижать её. SHAP позволяет определить не только направление влияния признака, но и величину его вклада.
Формула SHAP:
f(x) = E[f(X)] + Σᵢ φᵢ

SHAP используют для анализа отдельных предсказаний и для общего исследования модели. С его помощью можно выявлять наиболее важные признаки, находить неожиданные зависимости и проверять, на какие данные модель опирается при принятии решений.
При этом важно учитывать, что влияние признака на предсказание не означает причинно-следственную связь. Метод объясняет поведение модели, но сам по себе не доказывает, что изменение конкретного признака обязательно приведёт к изменению результата в реальной ситуации.

2. Принцип работы Isolation Forest
Isolation Forest - алгоритм машинного обучения для обнаружения аномалий. Он предназначен для поиска объектов, которые заметно отличаются от основной массы данных. Например, это могут быть подозрительные банковские операции, ошибки датчиков или необычная активность пользователей.
Принцип работы основан на случайном разделении данных. Алгоритм многократно выбирает признаки и случайные значения, по которым разделяет объекты, формируя деревья. В результате каждый объект постепенно отделяется от остальных.
Аномальные объекты обычно изолируются за меньшее количество разбиений, поскольку они отличаются от большинства наблюдений. Обычным объектам, которые находятся в плотных группах похожих данных, обычно требуется больше разбиений.
Основное преимущество Isolation Forest заключается в том, что ему не обязательно заранее предоставлять размеченные примеры аномалий. Это полезно, когда неизвестно, какие именно объекты следует считать подозрительными.
Однако результат зависит от параметров алгоритма и особенностей данных. Кроме того, необычный объект не всегда является ошибкой или угрозой, поэтому найденные аномалии при необходимости проверяют дополнительно.

3. Что такое генетические алгоритмы и как они работают
Генетические алгоритмы - методы оптимизации, основанные на принципах естественного отбора и эволюции. Они используются для поиска хороших решений в задачах, где пространство возможных вариантов слишком велико для простого перебора.
Каждое возможное решение представляется в виде особи, а набор решений называется популяцией. Качество каждой особи оценивается функцией приспособленности, которая показывает, насколько хорошо решение соответствует цели задачи.
Работа генетического алгоритма состоит из нескольких этапов:
1. Создание начальной популяции. Формируется набор исходных решений, часто случайным образом.
2. Оценка приспособленности. Для каждого решения рассчитывается значение функции приспособленности.
3. Отбор. Более подходящие решения получают большую вероятность участвовать в создании следующего поколения.
4. Скрещивание. Два родительских решения объединяются, чтобы получить новые варианты.
5. Мутация. В решение вносятся случайные изменения, которые помогают сохранять разнообразие популяции.
6. Формирование нового поколения. Новые решения оцениваются, после чего процесс повторяется.
Например, генетический алгоритм можно использовать для поиска короткого маршрута между несколькими городами, настройки параметров модели машинного обучения или распределения ресурсов.
Главное преимущество метода - возможность исследовать большое количество сложных вариантов без полного перебора. Однако генетические алгоритмы требуют настройки параметров, могут занимать много времени и не гарантируют нахождения глобального оптимума.
